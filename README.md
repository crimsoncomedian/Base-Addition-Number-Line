# Number Line: Addition Facts in Other Bases

A quick practice interactive using the measurement model. Each problem is two nonzero single digits added in a base from 2 to 9. Students type the answer in that base, or tap Show me to watch the jumps on a number line labelled in that base: start at the first number, take one hop for each unit of the second number, and the landing spot is circled. Then a new problem appears.

Open `index.html` in a browser, no build step needed.
